# DartAlarm Dartspiel – Download

Das Dartspiel für Windows (PC und TV): Aufgabenspiel, Dice501, Crazy501, Half It, 4 Gewinnt, Big 6, Dart-ABC, Soccer und Zombies – mit Autodarts-Erkennung und Sprachausgabe.

## Herunterladen

**[→ Neueste Version herunterladen](https://github.com/HeikoS74/Dartspiel-Download/releases/latest)**

Dort unter „Assets“:

| Datei | Wofür |
|---|---|
| **Dartspiel-Setup-…exe** | Das Spiel für einen PC – Installer (Startmenü und Desktop) |
| **Dartspiel-…-portable.exe** | Das Spiel ohne Installation, z. B. vom USB-Stick |
| **Dartspiel-Host-Setup-…exe** | Turnier im WLAN: für den Host-PC, der die Spiele einstellt und alle Plätze im Viererbild zeigt |
| **Dartspiel-Platz-Setup-…exe** | Turnier im WLAN: für die bis zu vier Spiel-PCs (komplettes Spiel, verbindet sich mit dem Host) |

## Hinweise beim ersten Start

- Die Dateien sind nicht code-signiert. Windows zeigt deshalb „Der Computer wurde durch Windows geschützt“ –
  auf **Weitere Informationen** → **Trotzdem ausführen** klicken.
- **Dartspiel Host:** Windows fragt, ob die App im Netzwerk kommunizieren darf → **Private Netzwerke** zulassen,
  sonst erreichen die Spiel-PCs den Host nicht. Alle PCs müssen im selben WLAN sein (kein Gäste-WLAN).
