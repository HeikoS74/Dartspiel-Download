# DartAlarm Dartspiel – Download

Das Dartspiel für Windows (PC und TV): Aufgabenspiel, Dice501, Crazy501, Half It, 4 Gewinnt, Big 6 und Dart-ABC – mit Autodarts-Erkennung und Sprachausgabe.

## Herunterladen

**[→ Neueste Version herunterladen](https://github.com/HeikoS74/Dartspiel-Download/releases/latest)**

Dort unter „Assets“:

- **Dartspiel-Setup-…exe** – Installer (legt Verknüpfungen in Startmenü und auf dem Desktop an)
- **Dartspiel-…-portable.exe** – läuft ohne Installation, z. B. vom USB-Stick

## Hinweis beim ersten Start

Die Datei ist nicht code-signiert. Windows zeigt deshalb „Der Computer wurde durch Windows geschützt“ –
auf **Weitere Informationen** → **Trotzdem ausführen** klicken.
